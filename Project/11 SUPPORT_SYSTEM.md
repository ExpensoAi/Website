---

# 8. ESCALATION

If AI cannot solve the problem:

AI
↓
Support Ticket

If community cannot solve:

Community
↓
Support Ticket

---

# 9. SUPPORT AGENT

Agent can:

- View ticket
- Reply
- Change status
- Change priority
- Assign ticket
- Request additional information
- Attach help articles
- Resolve ticket

---

# 10. USER

User can:

- Create ticket
- Reply
- Upload attachments
- View status
- Close request
- Reopen where permitted

---

# 11. AUTOMATIC INFORMATION

The system may collect:

- Website browser
- Device type
- Application version if provided
- Operating system
- Ticket timestamp

Do not collect unnecessary personal information.
