# 5. MODULE: HELP CENTER

The Help Center must provide:

- Search
- Categories
- Articles
- Troubleshooting
- Related articles
- Contact support
- AI Help Assistant

Search must support natural language.

Example:

User:
"Why is my SMS transaction not appearing?"

The system should return relevant articles.

---

# 6. MODULE: AI HELP ASSISTANT

The AI Help Assistant must answer questions using the official Expenso AI knowledge base.

The AI must not invent functionality.

If confidence is low:

" I'm not able to confidently resolve this from the available documentation."

Then provide:

- Search Help Center
- Ask Community
- Contact Support
