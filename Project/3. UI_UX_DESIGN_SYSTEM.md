# EXPENSO AI WEBSITE
# UI / UX DESIGN SYSTEM

Version: 1.0

---

# 1. DESIGN DIRECTION

The website must inherit the visual identity of the Expenso AI Android application.

Design style:

Premium AI Fintech

Visual characteristics:

- Dark
- Minimal
- Modern
- Professional
- Futuristic
- Financial
- Trustworthy

---

# 2. COLOR SYSTEM

## Background

Primary:
Deep Black

Secondary:
Very Dark Navy

Surface:
Dark Navy / Black

## Brand

Primary:
Electric Blue

Secondary:
Cyan

AI Accent:
Blue-Cyan

## Typography

Primary:
White

Secondary:
Light Gray

Tertiary:
Medium Gray

Disabled:
Dark Gray

## Financial Colors

Positive:
Blue / Cyan / White depending on context

Negative:
Red

Warning:
Amber/Orange

Success:
Cyan/Blue or approved success color

---

# 3. LOGO

Use the official Expenso AI logo.

Required assets:

- Full logo
- Icon
- Favicon
- Dark version
- Light version

Do not redesign the logo without approval.

---

# 4. TYPOGRAPHY

Typography must be:

- Modern
- Clean
- Highly readable

Recommended hierarchy:

H1:
Large bold

H2:
Large semibold

H3:
Medium-large semibold

Body:
Readable regular

Caption:
Small regular

Button:
Medium semibold

Avoid excessive uppercase text.

# 6. BUTTONS

Primary:

Electric blue / blue-cyan

Secondary:

Dark surface with blue border

Danger:

Red

Buttons must have:

- Hover state
- Pressed state
- Disabled state
- Loading state

---

# 7. CARDS

Cards must use:

- Dark surface
- Subtle border
- Moderate radius
- Minimal shadow
- Optional blue glow

Do not overuse glassmorphism.

---

# 8. INPUTS

Inputs must have:

- Dark background
- Clear border
- Focus state
- Error state
- Disabled state
- Placeholder text

Search should have prominent focus styling.

---

# 9. CHAT UI

User messages:

Dark/blue surface

Support messages:

Dark surface with subtle cyan/blue indicator

AI messages:

Dark surface with AI icon

The AI interface must visually match Expenso AI.

---

# 10. COMMUNITY UI

Post card:

- Author
- Title
- Category
- Description
- Votes
- Comments
- Timestamp
- Status

Feature request cards must display status prominently.

---

# 11. SUPPORT TICKET UI

Display:

Ticket ID
Subject
Status
Priority
Created date
Last update

Use status badges.

---

# 12. ANIMATION

Allowed:

- Fade
- Slide
- Scale
- Hover
- Number counter
- Chart animation
- AI typing indicator
- Page transitions

Animations must be subtle.

Avoid excessive animation.

---

# 13. RESPONSIVE DESIGN

Required breakpoints:

- Mobile
- Tablet
- Desktop
- Large Desktop

Mobile must not be a reduced-quality desktop layout.

---

# 14. ACCESSIBILITY

Requirements:

- Keyboard navigation
- Screen-reader labels
- Sufficient contrast
- Focus indicators
- Semantic HTML
- Accessible forms
- Accessible buttons
- Alt text

---

# 15. PRODUCT SCREENSHOTS

Actual Expenso AI application screenshots should be used whenever demonstrating functionality.

Screenshots should be displayed inside realistic device/browser frames where appropriate.

---

# 16. DESIGN PRINCIPLE

The website must immediately feel like the same product as the Expenso AI Android application.

A user should recognize:

"These are from the same Expenso AI product."
